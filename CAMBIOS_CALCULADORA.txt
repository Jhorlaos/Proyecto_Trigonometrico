3.2 Calculadora/src/main/java/com/calculadora/ui/GraficasDialog.java (nuevo)
Ventana modal con función, unidad, mínimo, máximo y paso.
Rangos recomendados según función y unidad, con botón para restablecerlos.
Acepta punto o coma decimal, pero rechaza números no finitos y rangos inválidos.
asin/acos exigen entradas entre -1 y 1. Se permiten entre 2 y 10000 muestras.
SwingWorker ejecuta generación, guardado y renderizado fuera del hilo visual.
Los controles se deshabilitan durante el trabajo para impedir solicitudes dobles.
El cierre se habilita al terminar, para evitar abandonar un guardado a medias.
Muestra progreso, PNG, errores y advertencias de valores indefinidos.
Cada imagen usa un archivo único bajo graficas/, evitando sobrescribir otras.
La ruta completa se muestra al pasar el puntero por el mensaje de estado.
Si falla la imagen después del guardado, se informa qué serie quedó guardada.

3.3 Calculadora/src/main/java/com/calculadora/servicio/SerieService.java

3.4 Calculadora/src/main/java/com/calculadora/servicio/SerieServiceImpl.java
La búsqueda de la operación por símbolo se realiza en el servicio, no en la vista.
Se validan valores finitos, rango, paso, avance numérico, máximo de muestras,
función admitida, unidad angular y dominio de las funciones inversas.
split(";", -1) conserva el campo vacío: x; se convierte en un punto con y=null.
También se acepta None por compatibilidad.
Se rechazan filas malformadas, números no finitos y valores x no crecientes,
en vez de descartar silenciosamente datos y guardar una serie incompleta.
Se rechaza una serie vacía o sin ningún valor y definido.
Se reutiliza el guardado transaccional existente de SerieDAOImpl.

3.5 Calculadora/src/main/java/com/calculadora/integracion/PythonBridge.java
Python se ejecuta con UTF-8 y sin generar archivos .pyc.
Se usa primero ../.venv/Scripts/python.exe si existe, y py como alternativa.
La propiedad Java calculadora.python permite indicar otro ejecutable explícito.
La salida y los errores se recogen por separado en archivos temporales.
Esto evita esperar a un proceso con la tubería de salida llena.
Se limita cada proceso a 60 segundos; se termina si supera ese tiempo.
Se revisan el código de salida, la respuesta vacía y las respuestas ERROR;.
Los archivos temporales se eliminan al terminar.

3.6 python_scripts/Trig.py
Se rechazan entradas no finitas y modos angulares desconocidos.
La generación valida función, dominio, rango y número máximo de muestras.
Se usa un número acotado de iteraciones, en vez de un while acumulativo.
Los puntos indefinidos siguen saliendo como x; para conservarlos como NULL.
Los errores de argumentos de serie se informan y producen salida no exitosa.

3.7 python_scripts/Graficar.py
Se usa el motor Agg, que genera archivos sin abrir ventanas de Python.
SQLite se abre en modo de solo lectura: una ruta incorrecta no crea otra BD.
Se insertan cortes visuales cuando la tangente cruza una asíntota entre muestras.
Estos cortes no cambian los valores matemáticos guardados en SQLite.
Los ejes distinguen ángulos de entrada y de salida para funciones inversas.
Se cierran conexión y figuras incluso si ocurre un error.
Los errores de renderizado producen un código de salida no exitoso.
